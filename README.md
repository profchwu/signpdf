# 簽名PDF

在瀏覽器內上傳 PDF 與 PNG / JPG / WebP 簽名圖片，拖曳調整位置、等比例縮放，並下載合成後的 PDF。支援多頁、不同頁面尺寸、頁面旋轉與裁切框。PDF 與圖片不會傳送到伺服器，也不會寫入瀏覽器儲存空間；重新整理即清除編輯狀態。

## 本機執行

安裝 Node.js 後執行 `node preview.cjs`，開啟 http://127.0.0.1:4173 。靜態網站檔案均位於 `dist`，無須安裝依賴或編譯。請透過 HTTP 伺服器開啟，勿直接雙擊 HTML。

PDF.js 4.10.38 與 pdf-lib 1.17.1 已隨網站附上。原始 PDF 保留，僅將簽名圖片畫入所選頁面。此工具提供圖片簽名，並非憑證式數位簽章；密碼保護的 PDF 需先解除保護。

## 驗證

`verify.cjs` 使用 Playwright 與 Microsoft Edge，測試多頁上傳、移動、大小調整、下載、頁數保留、方向鍵刪除、無效 PDF 的錯誤處理與手機版溢位。以 0 / 90 / 180 / 270 度旋轉及非零裁切框的 PDF，重新渲染下載檔並比較签名邊界，誤差小於 2 個 PDF 單位。測試用 Playwright 載入路徑依本機環境設定。

WebMCP 提供選用的 `navigate_pdf_page` 功能，僅在支援的瀏覽器啟用。目前測試環境未提供原生 WebMCP，故未驗證該選用介面；一般使用流程不依賴它。
